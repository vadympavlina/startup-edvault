# Аудит симулятора стартапу · листопад 2026

Результат повного аудиту (швидкодія, безпека, доступність, надійність, баланс, дизайн-система, тексти).
Перевірки відтворюються командами `npm run audit:*` (див. `scripts/audit/`).

## Виміряно
- Завантаження: DOMContentLoaded ~217 мс локально; 36 JS-модулів (ланцюжок імпортів глибиною 8), ~1 МБ коду, 312 КБ шрифтів.
- Рендер екрана ~18 мс (найповільніший `ex-logo` ~54 мс); тиждень гри 0,1 мс; збереження 19 КБ (після всіх вправ), 100 КБ на 104-му тижні, ~560 КБ з фото логотипа.
- Клавіатура: фокус видно скрізь, модальні вікна тримають фокус, Esc закриває, масштаб 200 % без прокрутки.

## Знахідки за пріоритетом
**P0**
1. XSS: збережений текст виконується у вправах «Неймінг» (`ex2.js`) і «Маркетингова стратегія» (`ex-aud.js:89`), а також на сторінці викладача. Перевірка: `audit:xss`.
2. Немає захисту від падіння: 26 з 700 випадкових пошкоджень збереження ламають відмальовування, `render()` без `try/catch`, `okState` перевіряє мало полів. Пошкоджене автозбереження назавжди зависає на заставці. Перевірка: `audit:fuzz`.

**P1**
3. `save()` мовчки ковтає помилку переповнення сховища.
4. Баланс: пасивний гравець не банкрутує; B2C-ідеї майже не заробляють (домашка ~3,5 тис. ₴/міс. проти онлайн-запису ~168 тис.); кінцівка «компанію продано» у ботів не трапилась.
5. Доступність (axe): `role="tablist"` без `role="tab"` (8 екранів), `<select>` без імені, 8 `role="meter"` без імені, словник без доступу з клавіатури, контраст «Спробувати» 4,47:1, порядок заголовків, немає skip-link.
6. Завантаження на повільній мережі: немає `modulepreload`, ланцюжок імпортів глибиною 8.

**P2**
7. Дизайн-система: ~540 жорстких кольорів проти 11 змінних, 38 розмірів шрифту, 29 радіусів, нерегулярний `z-index`; `.btn` оголошено 13 разів, `body` 15, 14 `!important`.
8. ~41 % CSS не використано на 69 екранах.
9. Тексти: «вправа/завдання/справа/крок» змішані; символи ★ ✓ ✗ замість іконок.
10. Мобільна: вузька колонка у вступі вправи, нижня смуга перекриває вміст, вкладки без підписів.

**P3**
11. Немає CI (`.github`). 12. Немає офлайн-режиму (PWA). 13. Шрифт Caveat ~150 КБ.

## Не перевірено
Живий сайт, реальні скринрідери (VoiceOver, NVDA), реальні телефони й повільна мережа, правильність навчального змісту.

# Симулятор стартапу · Edvault

Навчальний симулятор стартапу з дев'яти етапів: ніша й продукт, аудиторія й бренд, позиціонування, ціна й гроші, гроші на старт, просування, команда, фриланс, платежі й капітал. Понад п'ятдесят вправ, власна ідея, логотип з редактором фото, фінплан, торг з інвестором. Гра зберігається в браузері й у файл `.edvault`.

Статична сторінка без збирання: `index.html` + `startupsim/`.

| Що | Де |
| --- | --- |
| Гра | `index.html` |
| Сторінка викладача для перевірки робіт (лише перегляд файлів збереження) | `startup-check.html` |
| Код гри (ES-модулі) | `startupsim/js/` |
| Стилі, шрифти | `startupsim/*.css`, `startupsim/fonts/` |
| Спільне збереження в файл (контрольна сума, назви файлів) | `shared/savefile.js` |
| Перенесення збереження зі старої адреси | `startupsim/js/migrate.js`, `tests/fixtures/old-redirect.html` |

## Запуск і тести

```
npm start                 # http://localhost:8080
npm test                  # модульні тести
npm run test:e2e          # браузерні тести (потрібен Playwright)
npm run test:e2e -- stages   # лише ті, у назві яких є «stages»
node tests/startup-full-e2e.mjs homework plant   # повний прогін гри (104 тижні, усі вправи)
```

Правила оформлення (темний режим, мова інтерфейсу) — у `CLAUDE.md`.

## Походження

Симулятор винесено з репозиторію `edvault-emulators`. Стару адресу `emulators.edvault.online/startup` замінює сторінка, що переносить збережену гру сюди.
